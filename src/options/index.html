Cài đặt kết nối

Kết nối extension với Listing Guard API bạn tin cậy.

Nhập địa chỉ gốc của API, không thêm /health.

API key được lưu cục bộ trong Chrome.

Ánh xạ cột Google Sheets

Nhập tên field theo đúng thứ tự các cột được sao chép, mỗi field một dòng. Mặc định Etsy: title, tags, description. Amazon: title, brand, bullet_points, description, search_terms, product_type. Chỉ lưu tên và thứ tự field, không lưu nội dung listing.

Nội dung listing chỉ được gửi tới API này khi bạn chủ động kiểm tra listing.
